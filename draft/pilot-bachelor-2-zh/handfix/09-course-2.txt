163| \section{带迟滞的比较器；无稳态多谐振荡器}
164| 
165| \begin{proposition}[迟滞比较器]\label{prop:b2:feedback-oscillators:schmitt}
166| \index{迟滞比较器}\index{施密特触发器}
167| 具有\emph{正}反馈的运算放大器——输出端接至 $+$ 输入端，
168| 其间经分压器 $R_1$、$R_2$ 相连（此时 $+$ 输入端电位为 $\beta s$，其中
169| $\beta = R_1/(R_1 + R_2)$，信号 $e$ 加在 $-$ 输入端）
170| ——它没有稳定的线性区：输出停留在 $+V_{\text{sat}}$ 或
171| $-V_{\text{sat}}$ 之一，并在以下条件下翻转：
172| \begin{align*}
173| &\text{由 } +V_{\text{sat}} \text{ 变为 } -V_{\text{sat}} \text{，条件是 } e \text{ 升至高于 } +\beta V_{\text{sat}} ,\\
174| &\text{由 } -V_{\text{sat}} \text{ 变为 } +V_{\text{sat}} \text{，条件是 } e \text{ 降至低于 } -\beta V_{\text{sat}} .
175| \end{align*}
176| 两个阈值不同：\emph{迟滞}量 $2\beta V_{\text{sat}}$ 使比较器
177| 对小于该值的噪声不敏感，其在 $(e, s)$ 平面中的循环是一个
178| 沿顺时针方向运行的矩形。
179| \end{proposition}
180| 
181| \begin{proof}
182| 当 $s = +V_{\text{sat}}$ 时，$+$ 输入端电位为 $+\beta V_{\text{sat}}$；只要 $e < \beta V_{\text{sat}}$，
183| 输出就保持为正，$e$ 越过该值时即翻转——
184| 此后 $+$ 输入端电位为 $-\beta V_{\text{sat}}$，因此 $e$ 必须
185| 降到该值以下才能使其翻回。（在线性区内，正反馈会使任何偏差增大，
186| 即该状态是不稳定的。）
187| \end{proof}
188| 
189| \begin{proposition}[无稳态多谐振荡器]\label{prop:b2:feedback-oscillators:astable}
190| \index{无稳态多谐振荡器}\index{弛豫振子}
191| 将迟滞比较器的输出回送到其自身的 $-$ 输入端，
192| 经一个 $RC$ 电路（$R$ 从 $s$ 接到 $-$ 输入端，$C$ 从该处
193| 接到地）。电容器向 $\pm V_{\text{sat}}$ 充电，
194| 每当电压达到阈值便使比较器翻转：$s$ 处为方波，
195| $C$ 上为近似三角波，其周期为
196| \[
197| T = 2RC\,\ln\frac{1 + \beta}{1 - \beta} .
198| \]
199| 当 $\beta = 1/2$ 时，$T = 2RC\ln3 \approx 2.2RC$。这类\emph{弛豫
200| 振子}可为微控制器提供时钟、使指示灯闪烁，
201| 并产生函数发生器中的三角波和方波。
202| \end{proposition}
203| 
204| \begin{proof}
205| 当 $s = +V_{\text{sat}}$ 时，电容电压 $v_C$ 从
206| $-\beta V_{\text{sat}}$ 向 $+V_{\text{sat}}$ 按 $v_C = V_{\text{sat}} - (1 + \beta)
207| V_{\text{sat}}\eu^{-t/RC}$ 变化，电压达到 $+\beta V_{\text{sat}}$ 时所经时间为 $RC\ln[(1 + \beta)
208| /(1 - \beta)]$；比较器翻转，随后是对称的半循环。
209| \end{proof}
