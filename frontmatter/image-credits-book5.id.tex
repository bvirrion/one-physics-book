\chapter*{Kredit Gambar}

Gambar-gambar dalam buku ini adalah karya asli. Foto-fotonya digunakan
berdasarkan lisensi bebas masing-masing, dengan terima kasih kepada para
pembuatnya:

\begin{itemize}
  \item \emph{Bandul Foucault di Panthéon} (Bab 1): Olga
        Khomitsevich, Wikimedia Commons, CC~BY~2.0.
  \item \emph{Albert Einstein} (Bab 4): Orren Jack Turner, 1947,
        domain publik.
  \item \emph{Penemuan positron} (Bab 5): Carl~D. Anderson, 1932,
        domain publik.
  \item \emph{Konferensi Solvay 1927} (Bab 8): Benjamin Couprie,
        domain publik.
  \item \emph{Kondensat Bose--Einstein yang pertama} (Bab 19):
        NIST/JILA/CU-Boulder, domain publik.
  \item \emph{Latar gelombang mikro kosmik} (Bab 20):
        NASA / WMAP Science Team, domain publik.
  \item \emph{Replika transistor pertama} (Bab 24): pajangan Bell
        Laboratories, domain publik.
  \item \emph{Marie Curie} (Bab 25): Henri Manuel, sekitar 1920,
        domain publik.
  \item \emph{Detektor CMS dalam pembangunan} (Bab 26): Julian
        Williams, Wikimedia Commons, bebas dipakai dengan hak cipta.
  \item \emph{Nebula Kepiting} (Bab 27): NASA, ESA, J.~Hester dan
        A.~Loll (Arizona State University), domain publik.
\end{itemize}

Tautan sumber dan lisensi tiap foto ada dalam
\texttt{images/book5/CREDITS.md} di repositori buku ini.

\bigskip
Selain foto-foto tersebut, dua puluh enam gambar pada Bab 1--8 dan
11--27 adalah ilustrasi buatan kecerdasan buatan, dihasilkan dengan
pembangkit gambar OpenAI dari perintah yang ditulis oleh para
penyunting buku ini, dan diperiksa ketepatan fisikanya sebelum
dimuat. Perintah lengkap untuk setiap gambar tercatat dalam
\texttt{images/book5/ai/PROMPTS.md} di repositori.
