\chapter{电路中的电流定律与电压定律}\label{ch:g8:circuit-laws}

两台仪表，两个量——现在，终于轮到
“宪法”登场了。你将搭建的每一个电路，从手电筒
到城市电网，都遵循四条简短的定律：两条管电流的账，
两条管\omterm{def:g8:voltage-voltmeter:voltage}{电压}的账。掌握它们，再借助一点代数，
你就能算出尚未\omterm{def:g6:measurement-in-science:measuring}{测量}的读数——也能
找出任何“说谎”的\omterm{def:g6:measurement-in-science:measuring}{测量}结果。

\section{电流定律}

\begin{proposition}[串联回路的电流定律]\label{prop:g8:circuit-laws:seriesI}
沿单一回路，各处的\omterm{def:g8:intensity-ammeter:intensity}{电流强度}都相同：
\[
I_{\text{电池}} = I_{\text{灯泡 1}} = I_{\text{灯泡 2}} =
\dots
\]
一条道路，一路前行——上一章的收费站，如今
升格为宪法中的定律。
\end{proposition}

\begin{proposition}[节点定律]\label{prop:g8:circuit-laws:junction}
在任一\omterm{def:g5:series-parallel-circuits:parallel}{节点}处，同时流入的\omterm{def:g8:intensity-ammeter:intensity}{电流强度}之和
等于同时流出的\omterm{def:g8:intensity-ammeter:intensity}{电流强度}之和：对于一条干路分成
两条\omterm{def:g5:series-parallel-circuits:parallel}{支路}的情形，
\[
I = I_1 + I_2 .
\]
电荷既不会在分叉处产生、消失，也不会在此处储存：
来多少，去多少。（对任意多条\omterm{def:g5:series-parallel-circuits:parallel}{支路}均成立——
把流入求和、把流出求和，账目便平衡。）
\end{proposition}

\section{电压定律}

\begin{proposition}[串联回路的电压定律]\label{prop:g8:circuit-laws:seriesU}
在\omterm{def:g4:series-circuits:series}{串联}回路中，\omterm{def:g3:first-electric-circuit:battery}{电池}的\omterm{def:g8:voltage-voltmeter:voltage}{电压}在各用电器之间分配，
各部分之和恰好等于总\omterm{def:g8:voltage-voltmeter:voltage}{电压}：
\[
U_{\text{电池}} = U_1 + U_2 + \dots
\]
瀑布的比喻同样能说明这笔账：\omterm{def:g3:first-electric-circuit:battery}{电池}把
电荷的行进抬升至满高度，各用电器则
逐滴地分掉这段高度——良好的导线
则一分也不占用。
\end{proposition}

\begin{proposition}[并联支路的电压定律]\label{prop:g8:circuit-laws:parallelU}
\omterm{def:g5:series-parallel-circuits:parallel}{并联}的用电器都跨接在同样的两个\omterm{def:g5:series-parallel-circuits:parallel}{节点}之间，因此
同一\omterm{def:g8:voltage-voltmeter:voltage}{电压}对它们均适用：
\[
U_1 = U_2 = U_{\text{两节点之间}} .
\]
每条\omterm{def:g5:series-parallel-circuits:parallel}{支路}都获得两\omterm{def:g5:series-parallel-circuits:parallel}{节点}间的全部“推力”——
这正是\omterm{def:g5:series-parallel-circuits:parallel}{并联}\omterm{def:g3:first-electric-circuit:bulb}{灯泡}都能以额定亮度发光的原因，
也是家中每个插座提供相同
\qty{230}{V}。
\end{proposition}

\begin{example}[为什么分配不均？]\label{ex:g8:circuit-laws:unequal}
两个不同的\omterm{def:g3:first-electric-circuit:bulb}{灯泡}\omterm{def:g4:series-circuits:series}{串联}时通过的电流相同（定律一），
但\omterm{def:g8:voltage-voltmeter:voltage}{电压}却分配不均——\qty{2.1}{V} 与
\qty{2.4}{V}。较大的那一份，归于对电荷行进阻碍更大的\omterm{def:g3:first-electric-circuit:bulb}{灯泡}，
也就是说，阻碍更大的\omterm{def:g3:first-electric-circuit:bulb}{灯泡}承担更大的\omterm{def:g8:voltage-voltmeter:voltage}{电压}降。
所谓“阻碍更大”究竟指什么，以及如何\omterm{def:g6:measurement-in-science:measuring}{测量}它，
正是下一章的全部主题——本章的定律
则是它的舞台。
\end{example}

\section{先算后测}

\begin{method}[用四条定律求解电路]\label{met:g8:circuit-laws:solve}
已知某电路中的部分读数：
\begin{enumerate}
  \item 画出\omterm{def:g6:circuits-and-safety:diagram}{电路图}，并标出所有已知的 $I$ 和 $U$；
  \item 将适用的定律写成方程——\omterm{def:g5:series-parallel-circuits:parallel}{节点}处电流求和、
        回路中\omterm{def:g8:voltage-voltmeter:voltage}{电压}求和，并写出相同性条件：
        \omterm{def:g4:series-circuits:series}{串联}时 $I$、\omterm{def:g5:series-parallel-circuits:parallel}{并联}时 $U$ 相同；
  \item 解出未知量（代数课上学过的
        方程，此时终于派上用场）；
  \item 检验结果是否合理：没有哪个\omterm{def:g3:first-electric-circuit:bulb}{灯泡}获得的\omterm{def:g8:voltage-voltmeter:voltage}{电压}超过\omterm{def:g3:first-electric-circuit:battery}{电池}所能提供的，
        也没有哪条\omterm{def:g5:series-parallel-circuits:parallel}{支路}的电流超过干路的电流。
\end{enumerate}
\end{method}

\begin{example}[例题：混联电路]\label{ex:g8:circuit-laws:worked}
一节 \qty{6}{V} 的\omterm{def:g3:first-electric-circuit:battery}{电池}给\omterm{def:g3:first-electric-circuit:bulb}{灯泡} A 供电，\omterm{def:g3:first-electric-circuit:bulb}{灯泡} A 与
\omterm{def:g5:series-parallel-circuits:parallel}{并联}的一对\omterm{def:g3:first-electric-circuit:bulb}{灯泡}（B 和 C）\omterm{def:g4:series-circuits:series}{串联}。测得 $I_{\text{电池}} = \qty{0.5}{A}$，
$I_B = \qty{0.3}{A}$，$U_A = \qty{2.5}{V}$。求出其余的量。
\omterm{def:g5:series-parallel-circuits:parallel}{节点}电流定律：$I_C = 0.5 - 0.3 = \qty{0.2}{A}$。\omterm{def:g4:series-circuits:series}{串联}电流
定律：\omterm{def:g3:first-electric-circuit:bulb}{灯泡} A 通过全部 \qty{0.5}{A} 的电流。回路\omterm{def:g8:voltage-voltmeter:voltage}{电压}定律：
这一\omterm{def:g5:series-parallel-circuits:parallel}{并联}部分两端的\omterm{def:g8:voltage-voltmeter:voltage}{电压}为 $U_{\text{并联部分}} = 6 - 2.5 = \qty{3.5}{V}$；
\omterm{def:g5:series-parallel-circuits:parallel}{并联}\omterm{def:g8:voltage-voltmeter:voltage}{电压}定律：$U_B = U_C = \qty{3.5}{V}$。电路中每只
电表的读数现在都已知——用了四条定律，每条只需一行
代数运算。
\end{example}

\begin{example}[用定律辨别真伪]\label{ex:g8:circuit-laws:liedetector}
某实验报告称：\omterm{def:g3:first-electric-circuit:battery}{电池}\omterm{def:g8:voltage-voltmeter:voltage}{电压} \qty{4.5}{V}；两只\omterm{def:g4:series-circuits:series}{串联}\omterm{def:g3:first-electric-circuit:bulb}{灯泡}的\omterm{def:g8:voltage-voltmeter:voltage}{电压}分别为
\qty{2.1}{V} 和 \qty{2.9}{V}。按回路\omterm{def:g8:voltage-voltmeter:voltage}{电压}定律把各份\omterm{def:g8:voltage-voltmeter:voltage}{电压}相加：
共 \qty{5.0}{V}，而\omterm{def:g3:first-electric-circuit:battery}{电池}只“付出”了 \qty{4.5}{V}——不可能；
有人读错了表盘。另一份报告称：\omterm{def:g5:series-parallel-circuits:parallel}{节点}处电流为
\qty{0.40}{A}，两条\omterm{def:g5:series-parallel-circuits:parallel}{支路}电流分别为 \qty{0.25}{A} 和 \qty{0.20}{A}
——分叉处“凭空多出”了 \qty{0.05}{A}，予以否定。在定律出现之前，
错误的读数看起来与正确的一样可靠；如今，
这部“宪法”逐页审核每一个数据。
\end{example}

\begin{remark}[同样定律下的电池]\label{rem:g8:circuit-laws:batteries}
“首尾相接”的规则，正是\omterm{def:g4:series-circuits:series}{串联}\omterm{def:g8:voltage-voltmeter:voltage}{电压}定律穿着它最古老的
“外衣”：\omterm{def:g4:series-circuits:series}{串联}\omterm{def:g3:first-electric-circuit:battery}{电池}的\omterm{def:g8:voltage-voltmeter:voltage}{电压}相加（$1.5 +
1.5 + 1.5 = \qty{4.5}{V}$——这正是这组\omterm{def:g3:first-electric-circuit:battery}{电池}的秘密），
而一节接反的\omterm{def:g3:first-electric-circuit:battery}{电池}会\emph{减去}\omterm{def:g8:voltage-voltmeter:voltage}{电压}，它的“推力”用于对抗其余\omterm{def:g3:first-electric-circuit:battery}{电池}，
定律对\omterm{def:g8:voltage-voltmeter:voltage}{电压}的提供者与消耗者一视同仁，区别只在于
它们贡献的正负号不同。
\end{remark}

\section{周末问题：密封的神秘盒子}

\begin{problem}[{周末问题——电子俱乐部的
密封盒子挑战：四条定律对付四个谜团；
总审计}]\label{pb:g8:circuit-laws:1}
俱乐部把简单电路密封进盒中，只留出电表插孔。
各队须手持“章程”推断盒内电路——
工作台\omterm{def:g3:first-electric-circuit:battery}{电池}全程为 \qty{6}{V}。

\medskip\noindent\textbf{第一部分——盒子 A：两个\omterm{def:g3:first-electric-circuit:battery}{接线柱}、两
盏灯。}
标签注明：盒内只有两盏相同的灯，
或\omterm{def:g4:series-circuits:series}{串联}，或\omterm{def:g5:series-parallel-circuits:parallel}{并联}。
\begin{enumerate}
  \item 盒子 A 接到\omterm{def:g3:first-electric-circuit:battery}{电池}上时电流为 \qty{0.2}{A}；已知单独一盏同样的灯
        接在 \qty{6}{V} 上时，电流约为 \qty{0.4}{A}。
        \omterm{def:g4:series-circuits:series}{串联}还是\omterm{def:g5:series-parallel-circuits:parallel}{并联}？请
        用一条电流定律加以论证。
  \item 预测若改用\emph{另一种}
        接法，盒子将抽取多大电流。
  \item 在实际接法中，每盏内部\omterm{def:g3:first-electric-circuit:bulb}{灯泡}分得的\omterm{def:g8:voltage-voltmeter:voltage}{电压}是多少，
        依据哪一条\omterm{def:g8:voltage-voltmeter:voltage}{电压}定律？
  \item 在哪种接法下，内部的\omterm{def:g3:first-electric-circuit:bulb}{灯泡}会以
        额定亮度发光——为何从盒子的窥孔看去
        它们明显并不亮？
\end{enumerate}

\medskip\noindent\textbf{第二部分——盒子 B：三灯
谜题。}
盒子 B 内为：一盏灯（X）与一对\omterm{def:g5:series-parallel-circuits:parallel}{并联}的灯
（Y、Z——不一定相同）\omterm{def:g4:series-circuits:series}{串联}。
\begin{enumerate}[resume]
