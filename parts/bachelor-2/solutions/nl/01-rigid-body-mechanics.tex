\begin{solution}{exo:b2:rigid-body-mechanics:7}
(a) Het touw moet een netto koppel leveren om de katrol op gang te brengen:
$T_1 \ne T_2$. (b) $m_1a = m_1g - T_1$, $m_2a = T_2 - m_2g$,
$J\dot\omega = (T_1 - T_2)R$ met $a = R\dot\omega$:
$a = (m_1 - m_2)g/(m_1 + m_2 + J/R^2) = 0.5 \times 9.81/4.0 =
\qty{1.23}{m/s^2}$.
(c) $T_1 = m_1(g - a) = \qty{17.2}{N}$, $T_2 = m_2(g + a) =
\qty{16.6}{N}$.
(d) Massaloos: \qty{1.40}{m/s^2}. Energie:
$(m_1 - m_2)gx =
\tfrac12(m_1 + m_2 + J/R^2)v^2$; differentieer.
\end{solution}

\begin{solution}{exo:b2:rigid-body-mechanics:8}
(a) Gewicht $mg$ in het midden; muur: horizontale $N_w$ bovenaan; grond:
verticale $N = mg$ en horizontale wrijving $T = N_w$. Momenten om de voet:
$mg\,\tfrac{\ell}2\cos\theta = N_w\ell\sin\theta$. (b)
$T = N_w =
mg/(2\tan\theta) \le fmg \iff \tan\theta \ge 1/2f$. (c)
$\tan\theta \ge
1.25$, $\theta \ge \qty{51}{\degree}$. (d) Persoon op $x$:
$N = 4mg$, $N_w =
mg(\tfrac12 + 3x/\ell)/\tan60^\circ \le 4fmg = 1.6mg$:
$x/\ell \le (2.77 -
0.5)/3 = 0.76$.
\end{solution}

\begin{solution}{exo:b2:rigid-body-mechanics:9}
(a) Het contactpunt beweegt voorwaarts met $v + R\omega$ ($\omega > 0$ bij
terugspin): wrijving $-fmg$ op het middelpunt, $\dot v = -fg$; koppel
$-fmgR$ op de rotatie: $\dot\omega = -5fg/2R$. (b) De slip
$v + R\omega = v_0 +
R\omega_0 - \tfrac72fgt$ verdwijnt bij
$t_1 = 2(v_0 + R\omega_0)/7fg$, en dan is
$v_1
= v_0 - fgt_1 = (5v_0 - 2R\omega_0)/7$. (c)
$v_1 < 0 \iff R\omega_0 > \tfrac52v_0$. (d)
$t_1 = 16/(7 \times 1.96) = \qty{1.2}{s}$;
$v_1 = (10 - 12)/7 = \qty{-0.29}{m/s}$: hij komt terug.
\end{solution}

\begin{solution}{exo:b2:rigid-body-mechanics:10}
(a) Met $x$ in de trekrichting en wrijving $T$ langs $x$: $Ma = F + T$;
momenten om $G$ (tegen de klok in): $rF + RT = -kMRa$ (rollend,
$\omega_z
= -a/R$). Vandaar $a = F(R - r)/(1 + k)MR > 0$: de klos rolt
\emph{naar de trekrichting toe} en wikkelt de draad op. (b)
$T = -F(kR + r)/(1 +
k)R$ (achterwaarts); geen slip als
$F \le fMg(1 + k)R/(kR + r)$. (c) De werklijn van de draad raakt de naaf;
haar moment om het contactpunt $I$ is $F(r - R\cos\beta)$, met de klok mee
(voorwaarts rollen) wanneer $\cos\beta >
r/R$, en nul wanneer de lijn door
$I$ gaat --- de ogenblikkelijke as --- en dan is
$a = F(R\cos\beta - r)/(1 + k)MR$, $T = -F(kR\cos\beta + r)/(1 + k)R$,
$N = Mg - F\sin\beta$. (d) Voor $\cos\beta < r/R$ is het moment om $I$ tegen
de klok in: de klos rolt \emph{weg} van wie eraan trekt.
\end{solution}

\begin{solution}{exo:b2:rigid-body-mechanics:11}
(a) $Mv_0 = P$; om $G$: $\tfrac25MR^2\omega_0 = P(h - R)$ (voorwaartse
rotatie voor $h > R$). (b)
$v_0 = R\omega_0 \iff 2R = 5(h - R) \iff h = \tfrac75R$; erboven is
$R\omega_0 > v_0$ (voorwaartse rotatie), eronder terugspin. (c)
$\omega_0 = 0$: hij glijdt gedurende $t_1 = 2v_0/7fg = \qty{0.44}{s}$, over
een afstand $v_0t_1 -
\tfrac12fgt_1^2 = \qty{1.1}{m}$. (d) Een band op
hoogte $\tfrac75R$ stuurt de bal rollend zonder slippen terug: geen
glijfase, geen snelheidsverlies aan het laken, een voorspelbare
terugkaatsing.
\end{solution}

\begin{solution}{exo:b2:rigid-body-mechanics:12}
(a) $v_G = (R - r)\dot\theta$; het contactpunt staat stil, dus draait de
cilinder om zijn as met $\omega = v_G/r = (R - r)\dot\theta/r$. (b)
$E_k = \tfrac12Mv_G^2 + \tfrac12\cdot\tfrac12Mr^2\omega^2 = \tfrac34M(R - r)^2
\dot\theta^2$,
$E_p = -Mg(R - r)\cos\theta$; $\dd E/\dd t = 0$ geeft
$\ddot\theta
+ \dfrac{2g}{3(R - r)}\sin\theta = 0$,
$T = 2\pi\sqrt{3(R - r)/2g}$. (c) Een glijdend punt: $2\pi\sqrt{(R - r)/g}$
--- rollen is trager met een factor $\sqrt{3/2}$, omdat een derde van de
energie rotatie is. (d) Tangentieel:
$M(R - r)\ddot\theta =
-Mg\sin\theta + T$, dus $T = \tfrac13Mg\sin\theta$;
in het keerpunt is $N = Mg\cos\theta_0$:
$f \ge \tfrac13\tan\theta_0 \approx \theta_0/3$.
\end{solution}

\begin{solution}{pb:b2:rigid-body-mechanics:1}
\textbf{1.} $v = \qty{25}{m/s}$, $\omega = \qty{80.6}{rad/s}$; bovenaan
\qty{50}{m/s}, onderaan $0$, vooraan $(25, -25)$: \qty{35}{m/s} onder
\qty{45}{\degree} naar beneden.

\textbf{2.} $\tfrac12Mv^2 = \qty{375}{kJ}$;
$4 \times \tfrac12J\omega^2 = \qty{13}{kJ}$; totaal \qty{388}{kJ}, de wielen
$3.3\%$.

\textbf{3.} $N_f + N_r = Mg = \qty{11.8}{kN}$, $N_fa = N_rb$:
$N_f = Mgb/L =
\qty{6.8}{kN}$, $N_r = Mga/L = \qty{5.0}{kN}$ --- de vooras
(met de motor).

\textbf{4.}
$P_r = \sum\mu_rN_iR\omega = \mu_rMgv = 0.012 \times 11772 \times 25 =
\qty{3.5}{kW}$;
luchtweerstand $\tfrac12 \times 1.2 \times 0.7 \times 625 = \qty{262}{N}$,
\qty{6.6}{kW}.

\textbf{5.} $(M + 4J/R^2)\dot v = -\mu_rMg - \tfrac12\rho C_xSv^2$,
$M_{\text{eff}} =
1200 + 41.6 = \qty{1242}{kg}$. Alleen \omterm{prop:b2:rigid-body-mechanics:power}{rolwrijving}:
$\dot v = \qty{-0.114}{m/s^2}$, $d = (25^2 - 12.5^2)/0.228 = \qty{2.1}{km}$.
Alleen luchtweerstand: $v = v_0\eu^{-x/\lambda}$,
$\lambda = M_{\text{eff}}/\tfrac12\rho C_xS = \qty{2.96}{km}$,
$d = \lambda\ln2 =
\qty{2.0}{km}$ (samen: $\qty{1.0}{km}$).

\textbf{6.} Gewicht, \omterm{def:b2:rigid-body-mechanics:contact}{normaalkrachten}, wrijving van de weg op de banden. De
voorwaartse wrijving op de voorbanden is de enige uitwendige horizontale
kracht en versnelt dus de auto; haar vermogen is nul (het contactpunt staat
stil); de kinetische energie komt van de motor --- inwendige arbeid.

\textbf{7.} $M\dot v = T_f - T_r$; voorwielen $2J\dot v/R = \Gamma - T_fR$;
achterwielen $2J\dot v/R = T_rR$. Optellen: $(M + 4J/R^2)\dot v = \Gamma/R$;
$M_{\text{eff}} = \qty{1242}{kg}$.

\textbf{8.} Momenten om $G$ (de horizontale krachten van de weg grijpen op
diepte $h$ aan, samen $M\dot v$): $aN_f - bN_r + hM\dot v = 0$ met
$N_f + N_r = Mg$, dus $N_r = Mga/L + Mh\dot v/L$: de achteras wint
$Mh\dot v/L$, de vooras verliest evenveel.

\textbf{9.} Voorwielaandrijving: $M\dot v \le fN_f = f(Mgb/L - Mh\dot v/L)$,
dus $\dot v_{\max} = fgb/(L + fh) = 11.77/3.04 = \qty{3.9}{m/s^2}$.
Achterwielaandrijving: $M\dot v \le f(Mga/L + Mh\dot v/L)$,
$\dot v_{\max} = fga/(L - fh) = \qty{4.0}{m/s^2}$. De gewichtsverplaatsing
helpt de achteras: achterwielaandrijving, met het gewicht achterin, versnelt
harder.

\textbf{10.}
$\Gamma = RM_{\text{eff}}\dot v_{\max} = 0.31 \times 1242 \times 3.87 =
\qty{1.5}{kN.m}$;
$P = \Gamma v/R = 1490 \times 13.9/0.31 = \qty{67}{kW}$.

\textbf{11.}
$\dot v_{\max} = 0.1 \times 9.81 \times 1.5/2.655 = \qty{0.55}{m/s^2}$;
\qty{25}{s} tot \qty{50}{km/h}.

\textbf{12.} Grijpend: \omterm{thm:b2:rigid-body-mechanics:coulomb}{statische wrijving}, geen slip, geen dissipatie in het
contact. Doorslippend: \omterm{thm:b2:rigid-body-mechanics:coulomb}{kinetische wrijving} (iets kleinere coëfficiënt),
waarvan de arbeid de band verhit en het ijs polijst of doet smelten, terwijl
het vermogen van de motor in het rondtollen van het wiel gaat en niet in de
beweging van de auto.

\textbf{13.} Het remkoppel is inwendig (wiel--carrosserie); de auto wordt
alleen afgeremd door de achterwaartse wrijving van de weg op de band. Voor
het wiel (met verwaarloosbare $J\dot\omega$):
$\Gamma_b \approx T_iR \le fN_iR$.

\textbf{14.} Dezelfde balans met $\dot v = -\gamma$:
$N_f = Mgb/L + Mh\gamma/L$; bij $\gamma = fg = \qty{7.85}{m/s^2}$:
$N_f = 6792 + 1992 = \qty{8.8}{kN}$, $N_r =
\qty{3.0}{kN}$.

\textbf{15.} $\gamma_{\max} = fg = \qty{7.85}{m/s^2}$;
$d = v^2/2\gamma = \qty{40}{m}$; nat, $f = 0.45$: $\qty{4.4}{m/s^2}$,
\qty{71}{m}.

\textbf{16.} Gelijke koppels geven gelijke krachten, maar de achteras draagt
slechts \qty{3.0}{kN}: zij blokkeert het eerst. De wrijving op een glijdende
band is tegengesteld aan haar \omterm{def:b2:rigid-body-mechanics:rolling}{slipsnelheid} en kan geen zijdelingse kracht
meer leveren: een geblokkeerde achteras verliest de koersvastheid en de auto
tolt.

\textbf{17.} Geblokkeerd: $\gamma = 0.7g = \qty{6.9}{m/s^2}$, $12\%$ minder,
remweg \qty{45}{m} in plaats van \qty{40}{m} --- en geen stuurwerking meer.
Een antiblokkeersysteem merkt dat een wiel naar blokkeren toe vertraagt,
laat de rem vele keren per seconde los en zet haar weer aan, en houdt de
band zo dicht bij de statische piek en aan het rollen.

\textbf{18.} \qty{388}{kJ} in $4 \times 6 \times 470 = \qty{11.3}{kJ/K}$:
$\Delta T =
\qty{34}{K}$ per stop. Een vrachtwagen van \qty{40}{t} die
\qty{1000}{m} daalt, moet $Mgh = \qty{390}{MJ}$ kwijtraken: de remmen raken
oververhit en verliezen hun werking; een grindbaan brengt de vrachtwagen tot
stilstand door de wrijving van het grind.

\textbf{19.} $0.7 \times 388 = \qty{272}{kJ} = \qty{0.075}{kWh}$; een accu
van \qty{50}{kWh} is ongeveer $660$ van zulke stops waard.

\textbf{20.} $Mv^2/\rho \le fMg$:
$v \le \sqrt{fg\rho} = \qty{19.8}{m/s} =
\qty{71}{km/h}$; nat
\qty{53}{km/h}.

\textbf{21.} Zijdelingse wrijving $Mv^2/\rho$ op diepte $h$, \omterm{def:b2:rigid-body-mechanics:contact}{normaalkrachten}
op $\pm w/2$: $(N_{\text{out}} - N_{\text{in}})\,w/2 = Mv^2h/\rho$, dus
$\Delta N =
Mv^2h/\rho w$. De binnenste wielen komen los bij
$\Delta N = Mg/2$:
$v = \sqrt{g\rho w/2h} =
\qty{25.9}{m/s} = \qty{93}{km/h} > \qty{71}{km/h}$:
hij slipt dus eerder (omdat $f <
w/2h = 1.36$).

\textbf{22.} Op een verkanting met hoek $\beta$ en zonder wrijving geldt
$N\sin\beta =
Mv^2/\rho$ en $N\cos\beta = Mg$:
$v = \sqrt{g\rho\tan\beta} = \qty{9.3}{m/s} =
\qty{33}{km/h}$ voor
\qty{10}{\degree}.

\textbf{23.} $\omega_0 = \qty{6.28}{rad/s}$,
$J\dot\omega = \qty{-0.05}{N.m}$: $t =
\qty{126}{s}$;
$\tfrac12J\omega_0^2 = \qty{20}{J}$ gaat verloren.

\textbf{24.} De \omterm{thm:b2:rigid-body-mechanics:coulomb}{kinetische wrijving} $fN = \qty{2.4}{kN}$ duwt de auto
vooruit: $\dot v = 2400/1200 = \qty{2.0}{m/s^2}$; op het wiel geldt
$J\dot\omega = -fNR$, $\dot\omega = \qty{-744}{rad/s^2}$. De slip
$R\omega - v$ begint bij \qty{1.95}{m/s} en daalt met $\qty{233}{m/s^2}$:
zij verdwijnt in \qty{8.4}{ms}, waarbij de auto \qty{1.7}{cm/s} heeft
gewonnen en \qty{70}{\micro m} is opgeschoven --- een schokje, geen zet.

\textbf{25.} Rollen: wrijving $\approx 0$, rolweerstand $\mu_rN$,
$|T| \le fN$ triviaal. Versnellen: voorwaartse wrijving op de aangedreven
banden, $T \le fN_{\text{aandr}}$, $\dot v \le fgb/(L + fh)$. Remmen:
achterwaartse wrijving op alle banden, $T_i \le fN_i$, $\gamma \le fg$.
Bochten nemen: zijdelingse wrijving $Mv^2/\rho \le fMg$. In elk geval doet
één kracht --- de wrijving van de weg, begrensd door de wet van Coulomb ---
het hele werk.
\end{solution}
